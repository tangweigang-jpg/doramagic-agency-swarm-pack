# Quick Start

## Outcome

give AI coding hosts a verifiable agency-swarm workflow with multi-agent coordination rules, boundary checks, and recovery steps for agent communication failures

## Two-Minute Path

1. Read `AGENTS.md`.
2. Copy the relevant host instruction into your AI coding host.
3. Run `06_EVALS/smoke_check.md`.
4. If the check fails, open `03_PITFALL_LOG.md`.

## Official Upstream Entry

```text
pip install -U agency-swarm
```

Source: https://github.com/VRSEN/agency-swarm
